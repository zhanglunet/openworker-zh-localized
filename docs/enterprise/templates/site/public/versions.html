三个版本，一条单向链

原版做平台，中文版补语言与国内生态，企业版补配置与资产。 三者不是分叉，是一条单向同步链：上游的改动会一路流下来， 而下游的定制不会被覆盖。

同步链路

每一层加了什么

原版 · 做平台

Agent 运行时、权限引擎、技能系统、MCP 客户端、19 类工具。 界面英文，内置 6 家模型服务商（OpenAI / Anthropic / Gemini / Bedrock / Vertex / Ollama），不提供预编译安装包。

github.com/andrewyng/openworker · MIT

中文版 · 补语言与生态

界面全量汉化；模型服务商从 6 家扩到 19 家，补齐 DeepSeek、 通义千问、Kimi、智谱、MiniMax、阶跃等国内厂商，并新增 自定义端点（任意 OpenAI 兼容地址）。提供 macOS 安装包。

github.com/zhanglunet/openworker-zh-localized · MIT

企业版 · 补配置与资产

企业化的机制都在中文版里、公开可用；企业版真正多出来的是 配置与资产：接哪个私有网关、装哪些技能、连哪套内部系统、 用什么品牌与更新源，以及一条私有仓的同步与发布流水线。

私有仓库，需授权访问。
