安装说明

macOS

下载 .dmg 后双击打开，把应用拖进「应用程序」。 首次启动如果提示「无法打开，因为无法验证开发者」， 在「应用程序」里右键点击图标 → 打开，再点一次「打开」即可。

Apple 芯片（M 系列）和 Intel 芯片的安装包不通用。 不确定的话：左上角 → 关于本机 → 看「芯片」还是「处理器」。

Windows

下载 .msi 后双击安装。若 SmartScreen 提示「已保护你的电脑」， 点「更多信息」→「仍要运行」。

仅支持 64 位 Windows 10 及以上。

更新

客户端会自动检查更新并在后台下载，重启应用即完成升级。 不需要手动重新下载安装包。
