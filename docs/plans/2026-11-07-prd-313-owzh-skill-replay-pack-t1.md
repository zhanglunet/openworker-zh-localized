# PRD-313/T1 设计：openworker-zh-localized 中文 skill 调用重放包（replay-pack/v1）

> trend issue #1576 · PRD 全文 adopted/PRD-313-owzh-skill-replay-pack.md · 10-30 日报候选（用户 2026-11-07 拍板"都做"）
> 批次统一主题「可重放决策账本」：每一步事前定、事后可重放；审计链记"发生了什么"，重放包证明"能再算出同一个结果"
> 借鉴对象：AiSOC（MIT）/ CopilotKit·OpenBot（MIT）——只借形态，零代码复用

## 0. 30 秒速览

每次中文 skill 调用落一个重放包：输入快照（指纹）+ 决策 + 输出；重放命令原样重算；对不上显形报账本失败，不静默给新数。

## 1. 统一 schema：replay-pack/v1

| 字段 | 内容 |
|---|---|
| schema_version | `"replay-pack/v1"`（固定） |
| action | 仓内动作标识（封闭枚举） |
| input | `{ snapshot_fingerprint, inputs }`——指纹算法固定且版本化 |
| decision | `{ chosen, why, rules_version }`——选了什么 / 为什么 / 规则版本 |
| output | `{ result, key_numbers }`——结果与关键数字 |
| replay | `{ command, expect: "byte-identical", status: MATCH\|MISMATCH\|NOT_RUN }` |
| audit | append-only，成败都记（与 PRD-289 RefAudit 同纪律） |

字段纪律：
- 记录 **append-only**；重放命令由账本自身携带（重放 = 原样再跑，不重新解释）
- 重放结论**二值**：MATCH / MISMATCH；MISMATCH 显形报账本失败，账本本身即失败证据（保留 mismatch 两侧产物供人工裁决）
- 错误码**封闭词表**（穷举，与各仓既有错误码纪律一致），解析不到/指纹缺失即报错不猜
- **重放面只读**：零网络、零写路径、零副作用——T4 以 AST 断言钉死
- 指纹算法一变，历史账本不得重算为"一致"（算法版本入账本）

## 2. 本仓关键动作与集成点

- **动作**：中文 skill 调用——落点在中文调用出口（zh_trigger_registry lookup，PRD-239 已并）
- **input**：中文指令原文
- **decision**：解析到的技能包 + 歧义候选处理（人工消歧 chosen 留痕）
- **output**：结果
- 集成方式：在动作出口追加写重放包（纯加法），具体模块路径与函数签名在 T2 落地时对齐现有代码并回填本设计文档；不改动既有动作行为

## 3. 重放校验判据（T3 闸门依据）

1. 重放 = 用账本里的 input + decision 原样再跑一遍动作的**纯函数面**
2. 输出与账本 output **逐字节一致** → MATCH
3. 不一致 / 指纹校验失败 / 依赖的规则版本已不存在 → MISMATCH（各配封闭错误码），显形且留痕
4. 重放结果永不写回业务数据；不产出"新结论"替代旧结论

## 4. 红线

- 红线：歧义列候选人工消歧留痕（承 PRD-299 线）；重放不静默取候选
- 红线：重放面零自动执行——任何人工确认门（发布/投递/审批/交易）在重放路径上一律不触发
- 红线：示例全虚构，文档与示例零真实主机名/IP/账号/密钥

## 5. 与相邻机制划界（T4 断言对象）

- 审计链（PRD-143/152/154 等）：记"发生了什么"；本条证明"能再算出同一个结果"——两者并存不互替
- 可逆改动包（PRD-275~288）：改完能回去；本条是做完能重算
- 独立复核（对抗式 verifier，PRD-162/171/186 等）：再算一遍的是独立实现；本条是**原样**重放同一过程
