# PRD-267/T1：skill-recorder 式中文实操转中文技能设计（录制 + 口语化触发词）

- 日期：2026-10-28

## 1. 目标与非目标

**目标**：录下中文用户做一次任务的**步骤与中文口头解说**（本地处理），经人 review 后提炼成**中文技能**，配**口语化触发词**（"帮我看看这个怎么弄"类的自然说法也能命中技能），让中文用户用母语自然唤起能力。

**非目标**：
- 不做语音转写引擎——"口头解说"以文本输入（打字/既有转写产物）进入录制管线，本条不做 ASR；
- 不替代 PRD-121 中文开箱叙事（故事层）与 PRD-183 中文角色包（包层）——本条是录制来源的技能层；
- 不上云：录制、脱敏、草稿、review 全本地。

## 2. 与既有能力的划界

| 既有能力 | 关系 |
|---|---|
| PRD-121 中文开箱叙事 | 121 是故事/引导；267 是实录技能，来源不同 |
| PRD-183 中文角色包 | 183 定义角色身份；267 技能可被角色包引用，不改变包结构 |
| 既有 quality-gate / release-gate 脚本 | 技能入库走既有质量门；本条新增"触发词规范"检查项 |
| PRD-264（feishu 同型录制） | 模式同源；本仓特色=中文口语化触发词层 |

## 3. 方案设计

### 3.1 中文实操录制模型（`zh-capture-v1`）

```json
{
  "schema": "zh-capture-v1",
  "captured_at": "<ISO8601>",
  "user": "<占位 ID>",
  "task_summary": "<任务一句话（中文）>",
  "steps": [
    { "seq": 1, "action_zh": "<步骤名（中文）>",
      "say_zh": "<用户口头解说原文（中文，可空）>",
      "tool": "<工具名>", "intent_zh": "<这一步为什么>" }
  ]
}
```

- `say_zh` 是本模型的特色字段——用户的原话解说（"这里要先选左上角那个，别点错了"）是技能口语化语气的来源；录制前弹确认：解说里不得含个人信息（确认框 + J 规则兜底）；
- 禁止字段：文件真实路径原文、账号、屏幕内容截取；
- 全字段中文为主，`tool` 等技术名保留原文。

### 3.2 脱敏规则（T2 单测）

| # | 规则 | 处置 |
|---|---|---|
| Z-1 | 手机号/身份证/邮箱模式（中文语境常见格式含全角） | 阻断：该步不落盘 |
| Z-2 | 疑似真实姓名+称呼组合（本地常见姓词典+称谓词） | 阻断 |
| Z-3 | 路径含用户名模式 | 替换 `<USER>` |
| Z-4 | 内部系统词汇（中文词典） | 替换 `<INTERNAL>` |

阻断式脱敏；规则表可扩充；中文全角/半角都覆盖。

### 3.3 中文技能草稿 + 口语化触发词（T3 核心）

技能草稿（SKILL.md 兼容，中文正文）：

```yaml
---
name: <技能名（中文或拼音）>
description: <一句话（中文）>
triggers:            # 口语化触发词（本 PRD 新增维度）
  canonical: ["<标准触发短语>"]
  colloquial:        # 口语变体，>=3 条/技能
    - "<自然说法 1>"
    - "<自然说法 2>"
    - "<自然说法 3>"
required_review: true
---
```

- **触发词规范**（T1 评审核心）：每技能 `canonical` 1 条 + `colloquial` ≥3 条；口语变体来自录制的 `say_zh` 归纳（真实说法优先于编造）；触发词不得与既有技能歧义冲突（T3 提供冲突检查——两技能触发词字面重叠率阈值）；
- 草稿经人 review（本地 diff）后入库，走既有 quality-gate。

### 3.4 人 review 入库门（T4）

- 未 review（`required_review: true` 且 review 块未签）不可入库（闸门硬拒）；
- 入库复扫 Z 规则 + 触发词冲突检查（双条件）；
- 入库目标 = 既有技能注册通道，版本从 0.1.0 起。

## 4. 安全红线

1. 本地处理零外联；解说与步骤全链不出本机；
2. PII 不入模型（无字段可装 + Z-1/Z-2 阻断双保险，全半角覆盖）；
3. 未 review 不可入库（闸门硬拒）；触发词冲突检查防误唤起；
4. 口语变体来自录制原文归纳，不编造用户没说过的"口语"冒充真实语料；
5. 示例任务/解说全虚构，零密钥。

## 5. T2–T5 任务拆分（按 PRD）

| 任务 | 内容 | 验收标准（PRD 原文口径） |
|---|---|---|
| T2 | 本地录制管线（步骤+解说） | 样例可产出中文时间线 |
| T3 | 中文技能草稿 + 口语化触发词 | 草稿可触发演示 |
| T4 | 人 review 入库门 | 未 review 不可入库，有测试 |
| T5 | 验收试运行：虚构中文任务→技能 | 本地处理；无密钥；触发词可用 |

## 6. T5 验收标准

1. 虚构中文任务回放产出中文时间线（含 say_zh）；Z-1/Z-2 样例步骤被阻断；
2. 草稿含 canonical+colloquial≥3 触发词，触发词来自 say_zh 归纳（可比对）；
3. 触发演示：canonical 与一条 colloquial 均能命中技能；与既有技能零冲突（冲突检查通过）；
4. 未 review 草稿被入库门拒绝；approved 后入库成功；
5. 全产物 PII/密钥扫描 0 命中；全程零网络。
