## 3. 中文 @语法

### 3.1 形态（T2 实现口径）

| 形态 | 示例（占位） | 解析目标 |
|---|---|---|
| 中文技能引用 | `@写周报` | 技能包（登记册内唯一中文名） |
| 带包限定 | `@hr/写周报（占位）` | 包内技能（跨包同名消歧用——显式限定优先于停下问） |

### 3.2 禁止形态（出现即 `REF_SYNTAX_ERROR`，不尝试理解）

- `@写周报 v2`——引用不带版本后缀（版本归属包管理，PRD-285）；
- `@写*周报`——通配/正则不定义；
- `@写 周 报`——中间空白不归一（空白是分隔符不是可忽略字符）。

## 4. @名→技能包解析 schema

### 4.1 产物 schema（T2 预埋）

```json
{
  "schema": "ref-resolution/v1",
  "raw": "@写周报",
  "kind": "zh-skill",
  "skill": "zh-写周报（占位名）",
  "pack": "hr（占位）",
  "meta_summary": {"positioning": "一句话定位（占位）", "triggers": 3},
  "resolution": {"status": "resolved|ambiguous", "candidates": ["zh-写周报（占位）", "…"], "strategy": "exact"}
}
```

- `meta_summary` 只有定位一句话与触发词计数——技能正文零读取零复制（登记册既有口径，与 239/T3 一致）。

### 4.2 归一与解析步骤（确定性）

1. **归一**（R4 显形规则，逐条固定）：全角→半角；繁体→简体（固定映射表，无词典扩展）；去首尾空白；不合并中间空白；
2. 取候选集：技能登记（267 产出清单 + 285 版本记录，只读）；
3. **归一后精确匹配**（中文名逐字全等）；
4. 候选数裁决：=1 resolved；=0 `REF_NOT_FOUND`（附可用技能名清单）；>1 `REF_AMBIGUOUS`——**列出候选（技能名+一句话定位）请用户选**，不猜（R1）；
5. 带包限定形态（§3.1）先按包过滤再匹配——显式限定是用户自己消歧，不算猜。

## 5. 歧义候选闸门（T3 预埋）

| 错误码 | 触发 | 行为 |
|---|---|---|
| `REF_SYNTAX_ERROR` | §3.2 禁止形态 | 报错回显位置 |
| `REF_NOT_FOUND` | 归一后候选 0 | 报错 + 可用技能清单（名+定位） |
| `REF_AMBIGUOUS` | 归一后候选 >1 | **停下问**：候选列表交用户选择；不猜、不按频次挑 |
| `REF_REGISTRY_CORRUPT` | 登记不变量破坏 | 报错显形 |

- 词表封闭；解析返回 `Resolution | Refusal` 二型；
- 用户选择的结果回写审计（`chosen_from_candidates` 字段）——人工消歧留痕可查。

## 6. 解析审计

- 每次解析追加：`{ts, raw, normalized, kind, status, candidates, chosen?, error_code?}`；
- `normalized` 字段记录归一产物——归一规则可回放验证（R4 显形闭环）；
- 只增不删；`ts` 注入。

## 7. 与 239/T3 触发词登记册的划界（防两套命中逻辑）

| 路径 | 输入 | 机制 | 归属 |
|---|---|---|---|
| @引用（本条） | 用户显式写 @中文名 | 精确+归一匹配，歧义列候选 | PRD-299 |
