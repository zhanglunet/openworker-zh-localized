## 2. 与 PRD-184（中文 build-in-public 栏目）的边界

| 维度 | PRD-184（栏目） | PRD-268（本条，接入与健康层） |
|---|---|---|
| 管什么 | 栏目内容叙事：信息架构、首更模板（目标/过程/踩坑/产物）、实录文章与更新节奏 | 来源接入健康：注册表、ToS/限流、doctor、主备切换与审计 |
| 不干什么 | 不自建任何源连接/请求——引用公开视频/笔记时一律向 268 要句柄 | 不写栏目内容、不做叙事与排版、不决定"引用哪个源" |
| 对接契约 | 184 向 268 要 `(source_handle, health_meta)`：拿句柄与健康元数据（当前态/限流余量/last_error）写进文章引用区 | 268 只供句柄与健康元数据，不替 184 拉正文、不替 184 做内容判断 |
| 失效语义 | 184 引用时必须带 health_meta；源 degraded/failed 时 184 在文中标注"源状态不佳"而非静默引用 | 268 的 failover/restore 审计事件可供 184 文末"数据可靠性小记"引用 |
| 红线归属 | 无密钥/无内网信息（发布前扫描，归 184 T5） | 只接公开源、不绕登录墙、平台级限流退避（归 268） |

**要点**：184 是 268 的**唯一内容消费方**（栏目叙事），但它拿到的永远是"句柄 + 健康元数据"，不是直连。184 需要新源时，向 268 提注册需求（zh-source-v1 条目），由 268 的注册表与 doctor 接管其健康。

## 3. 与 PRD-211（图解上手指南）的边界

| 维度 | PRD-211（指南） | PRD-268（本条，接入与健康层） |
|---|---|---|
| 管什么 | 指南产出：核心路径图解、步骤图规范、可复制中文模板库 | 来源接入健康：同 §2 |
| 不干什么 | 不维护任何在线源连接——图解里的"示例页面"始终用本地样例或占位图 | **不自动下载图片**：268 不为图解批量抓取截图/图片素材 |
| 素材契约 | 图解素材（截图/示意图）来源仍是**人工采集 + 人工审核**，此纪律不因 268 存在而改变 | 268 提供的只是"源活着吗"的健康元数据；若指南需要引用在线示例，同样走 `(source_handle, health_meta)` 契约，与 184 同规 |
| 红线归属 | 素材合规与版本时效（截图易脱节→以步骤文字为主、截图为辅） | 只接公开源、不绕登录墙；**图片批量下载属于对抗风险行为，明确不在 268 范围** |

**要点**：211 的产出形态是"图解 + 模板"，天然倾向"多放截图"。本边界把这条路径**显式关死**：268 只做公开源健康探测与页面元数据可达性，**不做图片自动下载**；指南素材继续人工采集、人工审核。

## 5. 共同红线（三方共同遵守）

1. 文档与示例不得出现真实内部主机名、IP、账号或密钥，一律用占位符（`example.com` / `<公开页路径>`）；
2. 不绕登录墙：268 的 `auth` 只允许 `none`；184/211 不引用任何需要登录才能看的内容；
3. 遵守 ToS/robots/限流：268 平台级限流预算 + 429 退避 + `disallowed` 停用不对抗；184/211 不诱导读者绕过任何访问限制；
4. 实现类 PR 只开不合并，等用户 review。
