# PRD-452/T2 开发记录：翻译监督台最小实现（2026-11-15）

> trend issue #2156。承接 T1 设计草稿（#153 已合）。

## 交付

- `scripts/translation_supervision_bench.py`：TranslationSupervisionBench（按原文段的译稿状态机 出稿中→待人审→已点头/已发回/已关闭；版本 +1 并列可查）+ annotate（锚定段/行/术语，类型 换术语/重译/疑问/通过）+ resolve_annotation（已采纳/已驳回）+ send_back（多条批注打包成一条反馈，发回指令 换术语/重译整段/只改指定处）+ return_draft（版本 +1，旧批注逐条对照：已处理/未处理继续挂新版）+ approve（只能点头最新版本，未处理批注拒点头；点头动作本身是落账记录）+ outlet（人工拍板收件箱只收已点头）+ TranslationSupervisionLedger（JSONL append-only）。
- `tests/test_prd452_t2_translation_supervision_bench.py`：12 例全绿（版本链/打包发回/批注对照未处理挂新版/关口未点头不进收件箱/点头落账/落库/词表/AST 零网络）。
