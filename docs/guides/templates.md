# 中文模板库（可直接复制）

> PRD-211/T3（trend #1057）：每条模板都可复制后直接改占位符使用；占位符一律写成
> `【占位：说明】` 形态，模板逐个实测可用（tests/test_prd211_t3_templates.py 机检）。

## 一、配置模板

最小可用配置（复制到 `~/.config/coworker/config.toml`，改模型名即可；其余键全部可选）：

```toml
model = "【占位：模型名】"
mode = "interactive"
max_iterations = 12
```

关闭学习记忆总开关（不需要个性化时）：

```toml
[learning]
enabled = false
```

## 二、首任务提示模板

首次使用的三条最短任务话术（把【占位】换成你的真实内容）：

```text
帮我写一封【占位：收件人】【占位：目的】的邮件，语气正式一点。
```

```text
帮我做一份【占位：月份】的报表，重点看【占位：关注项】。
```

```text
帮我整理这份数据，按【占位：维度】分组，标出异常行。
```

## 三、角色包唤起模板

中文角色包的口语化唤起（装好角色包后任选一种说法）：

```text
让【占位：角色名】来看看这段话有没有问题。
```

```text
【占位：角色名】，帮我写个【占位：交付物】。
```

## 四、会话续跑模板

新会话开始时，用一句话找回上次进度（对应会话上下文注入的横幅提示）：

```text
展开坑点
```

```text
展开未决项
```

```text
忽略上次进度
```

## 五、纠正反馈模板

模型口径不对时，用这种句式纠正（纠正是会学习的记忆的输入，越具体越有用）：

```text
这列不该这么算：【占位：列名】应该用【占位：正确口径】，而不是【占位：错误口径】。
```

## 六、命令速查

```bash
owzh run "【占位：任务】"
owzh status
```
